Measurement protocol

Single-threaded JMH 1.37 on Oracle JDK 25.0.1. Each fresh JVM runs two 500 ms warmups and three 250 ms measurements. Each randomized ABBA or BAAB block contains four JVMs. Every case has eight parent-versus-parent calibration blocks, twelve unprofiled parent-versus-commit timing blocks and four separately profiled blocks. The timing verdict uses one prespecified two-sided test per case. Confidence intervals are per case. All completed forks are included. The governor is checked before, during and after each fork.

Calibration estimates the slowdown detectable with 80% power at twelve timing blocks. Profiled cycle and instruction changes use paired log ratios. Allocation is the candidate-minus-parent difference in Java heap bytes per 16-block JMH operation. Four profiled blocks give a minimum two-sided p of 0.125. All 95% counter intervals span every possible change. Each card shows the raw and Holm-adjusted p-values.

The commit changes the width-specific plain pack or unpack bodies at 1, 13 and 25 bits in this set. The corresponding bodies at 3, 8, 16 and 31 bits match between revisions. The measurements compare the two compiled JARs, including their JIT and code layout.
